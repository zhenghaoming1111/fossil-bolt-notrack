# 跨机器验证与版本边界

## 2026-11-19：原交付版本在 KVM 上的复现

| 项目 | 实测配置 |
| --- | --- |
| 系统 | Ubuntu 24.04.2 LTS，x86-64，Linux 6.8.0-54-generic |
| 虚拟化 / CPU | KVM，Common KVM processor，16 个 vCPU；宿主物理 CPU 型号未知 |
| 内存 | 32,863,308 KiB，约 31.34 GiB；无 swap |
| 文件系统 | ext4，根分区约 61 GiB；实验开始前约 59 GiB 可用 |
| 容器 / 工具 | 项目独立 Docker 29.10.0；离线交付镜像；Python 3.12.3 |
| LLVM / Fossil | LLVM BOLT 24.0.0git，固定提交 af3fdf39125a；Fossil 2.28，内嵌 SQLite 3.52.0 |
| CPU 分配 | 服务 CPU 0、客户端 CPU 1；四并发；仅本机回环 HTTP |
| profile | 在服务器上使用选项 ON 重新插桩、训练；B/C 共用同一份新 profile |
| perf 限制 | KVM 未开放 CPU PMU；未测 IPC、硬件分支失误率或 LBR |

这次是虚拟机上的跨机器复现。使用固定交付镜像，没有在服务器重新编译 LLVM，也没有在服务器重跑全部 LLVM 回归测试。原补丁、BOLT、数据和正式请求脚本未改变。

下表是逐轮配对的 **B→C 耗时下降中位数**，每格 24 轮；B/C 仅开关不同。

| 场景 | 评估种子 43 | 评估种子 44 |
| --- | ---: | ---: |
| 普通浏览 | 0.652% | 0.654% |
| 历史审查 | 0.790% | 0.989% |
| 统计看板 | 3.020% | 2.944% |

正向共 432 条正式计时，1,800 个页面指纹一致，请求错误为零。48 轮负对照共 96 条计时，配对下降中位数 −0.031%，95% 区间 [−0.150%, +0.133%]，通过预先设定的 1% 回退界限；这不表示有加速，也不保证所有程序绝对零回退。新机器无需重现原 WSL 的同一百分比。

**完整流程经过一次修正才完成。** 原镜像的正向流程与 `negative-check` 通过，随后 `negative` 在计时前因 ELF 元数据误报退出。保留首次失败后，使用额外校验辅助脚本审查原二进制，沿用原 profile 与计划首次完成负对照。原镜像未因此被修改。这次数据不能写成“原指引无修改一次通过”。

原始逐轮记录、训练数据和校验摘要保存在 [服务器证据](../evidence/server-20261119/)。可用 `python3 scripts/verify_server_results.py` 复核记录数、执行顺序、请求一致性、页面指纹及配对统计。该精简证据不包含旧服务器的全部二进制；重新执行程序请使用交付镜像生成新输出。

## repro-v2：修入正式交付

v2 将受限 ELF 校验纳入 `fossil_nonregression.py`，补充单元测试和主机预检。复现入口会拒绝混用 v1 镜像和 v2 材料。镜像仍使用原来的 BOLT 可执行文件、插桩库、Fossil ELF 和固定数据。

交付验收状态与日志索引保存在 `release-metadata/repro-v2-20261120/`；没有对应阶段的成功日志时，不应宣称它已经验收。2026-11-19 的性能表来自原实验，不能改名为 v2 重新测得的结果。
